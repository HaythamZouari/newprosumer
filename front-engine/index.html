Simulateur d'autoconsommation solaire

Projet : consommation → production → finance → résultats → rapport.

1. Courbe de consommation

Importez votre relevé (STEG / compteur) — formats .xlsx, .xls, .csv, .ods. Les 3 structures de courbe sont reconnues.
Pas de fichier ? Passez à « Construire par activité », ou continuez avec un profil d'exemple.

2. Production photovoltaïque

Choisissez la source : Ninja API, PVGIS API, ou import PVsyst (fichier).
La carte interactive s'affiche une fois l'application déployée (serveur). En aperçu, saisissez la latitude et la longitude.
Production validée.
